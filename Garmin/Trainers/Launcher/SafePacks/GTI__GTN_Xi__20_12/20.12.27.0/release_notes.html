GTN Xi Trainer v20.12

Trainer release aligned with v20.12 airborne software. Supports demos for the following new features:
  • Glide Range Ring and best airport glide indication for fixed-wing aircraft
  • Selectable knob default - pilots can change the outer knob's default function from Page Navigation to COM Radio as needed to accommodate workflow.
  • Selectable startup page - pilots can customize the default start page by selecting from a menu of available page options in the Systems Setup
  • Shortcut to view Charts from Active Flight Plan Page
  • Additional user-selectable fields to access data, functions, and other pages from the moving map.
